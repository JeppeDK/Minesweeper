# Minesweeper

A simple Windows version of Minesweeper with an online leaderboard.

🎮 Features
Easy, Medium, Hard and Impossible difficulties
Classic Minesweeper gameplay
Right-click to place/remove flags
Built-in timer
Online leaderboard
Best scores saved online
Custom Windows application icon

📥 Download

You can download the latest version from the Releases page.

Download Minesweeper.exe from the latest release and run it.

No Python installation is required.

🏆 Online Leaderboard

When you win a game, your best time is automatically uploaded to the online leaderboard.

Your best score for each difficulty is saved. A slower time will not replace your existing record.

🖥️ Windows

This game is currently made for Windows.

If Windows Defender or another antivirus program warns you about the application, make sure you downloaded it from the official GitHub Releases page.
